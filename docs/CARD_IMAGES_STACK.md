# 卡圖與戰場分層卡堆

主遊戲介面（index.html）的圖鑑、牌組、手牌、卡牌詳情、墓地、拖曳預覽與戰場使用 card-images 中的完整卡面。卡框維持 744:1039 比例；缺圖或載入失敗時保留黑色卡框。

## 卡圖索引

執行 `node tools/build-card-images.mjs` 可依官方卡牌資料與實際檔案重建 `data/card-image-index.json`。1100 筆卡牌中，1096 筆有卡圖，以下 4 筆使用黑色卡框：

- court_of_equity
- mobbed_court
- mock_court
- overflowing_court

變形與複製卡沿用 runtimeBase 卡圖；Druid 翻面使用背面卡圖。

## 戰場

每格由地表卡堆、地點分界、地下／水下卡堆組成。地點不是固定在所有單位的最底層。顯示位置由引擎的實際佔據格與所在層決定；無下層單位時收合空層。跨格大型單位以主卡及其他佔據格的連動標記呈現。

卡堆可展開查看完整卡面及即時狀態。「置頂」只儲存在介面的展示順序 Map，不修改遊戲狀態，也不允許跨層。跨層仍須執行引擎允許的合法移動。
