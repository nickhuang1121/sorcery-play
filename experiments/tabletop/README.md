# 森境牌桌 · 獨立視覺試玩

入口：`experiments/tabletop/index.html`。從專案根目錄啟動 HTTP server 後開啟此路徑。

這個資料夾只展示美術構圖、5×4 戰場、透視、牌堆、人物資訊、手牌拖曳／滑動、目標高亮、卡牌詳情、示意攻擊／治療與換回合。示意行動不實作完整官方規則。不載入 `src/app.js`、Firebase 或正式規則引擎，不存取 localStorage、sessionStorage 或正式對局。

只讀取現有的 `data/card-image-index.json` 與 `card-images/`。所有新樣式、腳本與場景圖片均位於本資料夾；沒有修改正式入口或共用檔案。選單可切換中英文、平面／透視、環境動態及重設場景。

場景圖片 `assets/forest-table.jpg` 由內建 image_gen 工具產生，再轉為 JPEG。提示詞：原創奇幻森林牌桌背景，高角度斜俯視，中央 65% 留空的低對比深色石板廣場；左側營火與帳篷，右側青綠魔法光的殘破石拱門，外圍樹木、苔蘚、蕨類與落葉；古典奇幻手繪風格。背景內不含格線、卡牌、人物、UI 或文字。卡圖沿用專案既有素材。

完整背景生成提示詞見 [forest-table.prompt.txt](assets/forest-table.prompt.txt)。

驗證：桌面 1440×900、手機橫向 844×390、直向 390×844；卡圖全部載入、拖曳放置地點、滑到手牌末端、閃電選目標、治療、攻擊、召喚、對手回合與抽牌、中英文切換、玩家資訊、點外側關閉、場景重設及透視切換。瀏覽器未出現錯誤。此為介面示意驗證，沒有以正式規則引擎進行對局。
