# Sorcery: Contested Realm · 本機網頁遊戲

原生 HTML、CSS、JavaScript ES Modules；無框架、無 npm 依賴與建置步驟。核心遊戲使用本機官方卡牌快照；可選 AI、本機雙人與四副官方 Beta 預組，自組牌可匯入、匯出及保存於 localStorage。線上雙人使用 Firebase 的 Google 登入與即時資料庫，兩端共用正式卡圖戰場。

在根目錄執行 `python3 -m http.server 8765`，開啟 `http://localhost:8765/`；也可用 VS Code Live Server。

線上對戰直接由 GitHub Pages 連接 Firebase，不需要另外啟動 Node。兩位玩家各自以 Google 登入，建立／加入同一房號，選牌組並準備後開始。保留雙方離線超過十五分鐘的自動清房。設定與朋友對戰的信任範圍見 [線上雙人對戰](docs/ONLINE_MULTIPLAYER.md)。

首頁提供「單機雙人」「新手教學」「單人 VS 電腦」「線上對戰（測試版）」與「編輯牌組」。已有未結束的存檔時可選「繼續上次對局」；已結束則可選「查看上次結果」。停留首頁時對局暫停。

新手教學包含七個獨立章節：認識卡牌、放置地點、召喚、移動與攻擊、施法與取消、防禦與回合、整合練習。前六章以聚光遮罩限制可操作區域，並在提交行動時再次檢查步驟；最後一章撤掉遮罩，完成三項目標即可結束，不必打完整場。教學使用固定的專用場景與腳本對手，所有行動仍由正式規則引擎結算，不加入玩家牌組或官方預組。

教學進度另存於 `sorcery.tutorial.v1`，可從首頁繼續、重玩章節或退出；中途進度會透過操作重播恢復，不覆蓋 `sorcery.match`。教學介面同時支援繁體中文與英文，可由教學工具列切換。專項測試：`node --test tests/tutorial.test.js`。

介面採深石色與藍灰材質，首頁、戰場 HUD、卡牌資訊、選擇彈窗、牌組及線上大廳共用 `styles/arena.css`。合法位置使用藍白光暈，攻擊目標使用紅橙色，暖銅色只強調主要操作。卡牌詳情以右上 ×／點外面／Escape 關閉，選擇彈窗暫時關閉仍保留待決事項。教學的重來、章節、語言及退出收在「⋯」選單；線上大廳的手動 JSON 匯入收在進階區。

手機驗證涵蓋直向 390×844、橫向 844×390 的繁體中文與英文；完整重跑中文直向及英文橫向七章，並補測另外兩個組合。橫向目標自動捲動會同步戰場視角；選牌時取消按鈕取代無關捷徑，避免互相遮擋。既有補測頁另驗證效果暫時關閉、卡牌攤開／堆疊與勝負結果。

手牌手勢採方向判定：左右滑動瀏覽、明確向上拖曳出牌。觸控由瀏覽器保留原生慣性滑動；原生 `pointercancel` 不重建手牌區，展開／收起與更新畫面會保留同一玩家的捲動位置。滑動驗證涵蓋七張實際重播手牌、十四張溢位場景、直向／橫向及中英文；重現入口為 `tests/hand-swipe-ui.html`，完成後可還原原存檔。
