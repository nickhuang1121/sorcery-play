PROVENANCE

The art: every frame in this library is the deterministic output of rendering code --
geometry, curl-noise velocity fields, palette ramps, shading taken from the density
field's own gradient -- executed at the resolution it ships at. No image generator, no
diffusion model, no stock art, no scraped or hand-drawn source, no photographic source.

The code: the GDScript, the shaders and the scene files were emitted by Python build
scripts, and those build scripts were written with AI assistance.
